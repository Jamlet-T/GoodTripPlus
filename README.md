# GoodTripPlus

GoodTripPlus 是《以撒的结合：忏悔+》的 MiniMAPI 外置传送插件，基于 Goodtrip MLX's Tweak 开发。

## 安装

- 安装必需依赖 **MiniMAPI**，并将模组放入 `mods/goodtripplus`。
- 可选安装 **Mod Config Menu**；在 L 键菜单中选择 **GoodTripPlus** 调整设置。
- 停用 Goodtrip、Goodtrip MLX's Tweak 和 Lazy Delver，避免重复功能。
- 若已安装独立的 Secret Candidate Outlines，请停用它，避免候选门框重复显示。
- 安装或更新后重启游戏。

## 使用

按住地图键并用射击方向键移动光标，松开地图键传送；也可移动鼠标控制光标并左键点击目标房间。

堕化遗骸及其灵魂在地图操作期间会暂时屏蔽投掷身体的方向输入；松开地图键后，还需松开已按住的发射方向键，才恢复正常投掷。

默认可传送到符合条件的已探索、已清理房间及通路相邻目标。可在 MCM 中选择相邻房间、已探索房间或任意房间；任意房间模式随时允许传送至地图可选房间，绕过战斗、锁门和连通等限制，不消耗钥匙、金币或刺门生命费用，也不补时间，可能显著影响游戏平衡。

L 键菜单的“传送设置”中有两项奖励门开关：当前房间有恶魔房／天使房门时允许传送，以及有 Boss Rush／蓝子宫门时允许传送，默认都关闭。Boss Rush 门在深牢 II（含深牢 XL 等同章变体）20 分钟内、陵墓 II（含炼狱 II）25 分钟内可无视第二项；蓝子宫门在子宫 II（含同章变体和 XL）30 分钟内可无视第二项。限时豁免只放行对应门；同房间若有恶魔／天使房门，还须第一项开启。任一玩家持有山羊头（215）或圣餐（499）时，可无视两项设置与上述时限传出，仍须满足其他传送规则。红钥匙生成的常驻恶魔／天使房门不受这两项限制。

配置菜单保留六个功能页，并按小标题分组；“禁止传送”集中放置诅咒房及两类奖励门开关。初始房间高亮出厂默认开启，继续使用 MiniMAPI 的同一设置。更新不会覆盖已有 MCM / MiniMAPI 保存值；恢复单项默认时采用新版默认值。

## 功能

- **传送判定**：统一处理传送范围、房间状态、诅咒房限制和奖励门限制。
- **无怪房间清理判定**：已访问且出口开放的无怪普通房，以及完成后的挑战房，会在本模组的小地图与传送规则中视作已清理；不修改游戏房间状态。
- **相邻房门自动解锁**：可支付资源解锁当前相邻房门后传送，默认开启。
- **鼠标传送**：支持鼠标移动光标和点击传送，并与键盘操作共享判定规则。
- **地图记忆**：保存并恢复当前楼层的掉落物图标、门图和隐藏房探索状态。
- **rewind 修复**：修复使用控制台 `rewind` 后地图上的掉落物图标消失。
- **隐藏房标记**：显示并随探索更新隐藏房候选位置，标记布局与 MiniMAPI 对齐。
- **隐藏房候选门框**：在房间内显示白色普通、金色超级、红色究极隐藏房候选入口，并结合道具线索、踩踏、岩石波和整房间效果更新候选。已确认的真实门位保留到入口打开；完整来源按 ID 列在下方。
- **特殊房间标记**：标记深牢 II / XL 的愚者骷髅房及矿洞 II 的黄色轨道按钮房。
- **地图边界高亮**：按住地图键时显示地图边界房间。
- **战斗地图设置**：支持配置战斗时隐藏地图，以及在战斗中保留大地图。

传送过场保留两档：立即传送 / 淡入淡出。立即传送使用原生 ChangeRoom，没有过场、冷却最短，但不写原生沙漏快照（rewind 可能回到更早状态）。淡入淡出改用原生 FADE，避开复得游魂(t180)的传送后隐身 bug；无中转场景的实测中，rewind 能回到出发房，但恢复的是进房时的状态（会撤销在该房间内的后续变化）。旧的传送动画设置自动回退为淡入淡出。

## 隐藏房候选门框

隐藏房候选标记默认关闭，需要先在“房间标记”中开启。在 Mod Config Menu 的 GoodTripPlus 菜单中，可分别开关候选门框与迷失诅咒期间的门框显示，两项默认关闭；还可将候选门框不透明度设为 0%–100%（每档 5%），默认 50%。此设置只缩放候选门框的原有透明度，双类型的换色节奏不变；红钥匙原版门框的补绘不受影响。关闭原有的“显示隐藏房候选标记”会同时隐藏候选门框。设为 100% 时，单类型候选门框使用固定画面、固定颜色且不额外降低不透明度，不受游戏原版门框特效的动画影响；双类型候选门框只由本模组的白金换色曲线改变颜色和透明度。门框素材本身较透明，因此在同一位置叠绘增强亮度，单类型叠绘五次、双类型叠绘七次；设为 100% 时，双类型门框在换色过程中至少保持原有的 85% 颜色不透明度，叠绘不会增加闪动周期。真实隐藏房即使已显示在地图上，只要入口尚未打开，门框仍会保留供放置炸弹。下水道 II 镜中世界内，白色、金色及红钥匙红色门框的位置随房间画面水平镜像；左右墙面的门框朝向按镜像后的实际墙面旋转，上下墙面保持原有朝向，门框固定在对应墙面。

打开 L 键的 Mod Config Menu 时，本模组绘制的所有门框会暂时隐藏，避免盖住菜单；关闭菜单后立即恢复，候选位置与排除证据仍照常更新。

门框开启时，小地图候选星号与门框共用狗牙无叫声和“嘿，听好！”的排除规则；持有状态变化会立即刷新门框。星号代表地图位置，门框只画当前房间可用的入口，所以其他房间的星号不要求在本房间有门框。进入与假候选相邻的房间后，若该方向的门位被房间布局禁用，假候选与对应星号会一起移除；真实隐藏房入口仍受保护。已揭露的真实隐藏房会隐藏星号，但未打开的入口仍保留门框。星号还受地图键淡入、MinimapAPI 战斗隐藏和迷失诅咒影响；若启用了诅咒期间的门框显示，门框不会随诅咒一起隐藏。

持有红钥匙、碎裂钥匙（含额外卡牌槽）或该隐魂卡时，或虚空（477）吸收了红钥匙后仍持有虚空时，或处于红钥匙开启的额外房间且原版仍显示门框时，原版红色门框会在普通房间、特殊房间、额外房间及回溯线／家园中统一补绘为清晰的固定红色。回溯线与家园只识别当前房间实际存在的原版红钥匙门框，不计算隐藏房候选。补绘使用当前房间实际存在的原版门框特效定位，不自行猜测新门位；同一门位若已有本模组候选门框，只绘制一次增强门框。

候选按已进入的房间、地图上已显示的房间位置与已公开的房间图标逐步计算。普通隐藏房候选至少需要两面已知相邻房墙；同一间三格 L 型大房间的两面墙也计为两面。只有一面已知邻墙、其他普通房间尚未全部探索时，该位置可能再出现第二面邻墙，暂以白金交替显示；已知邻墙达到两面后固定为白色，不再出现金色。超级隐藏房只可能与一间非特殊房间相邻，且必须是死路；紧邻两面或更多已知房墙时立即排除金色。小地图星号与房间门框使用同一候选表；单类型固定显示，双类型沿平滑的白金换色曲线循环。地图已显示但未进入的普通灰色房格只提供位置和外形，不提前读取真实类型或门位；窄房长边无法生成隐藏房门位。普通隐藏房已被发现后，剩余单面普通房墙的双类型候选改为金色；超级隐藏房已被揭露后，剩余单面房墙的双类型候选直接消失，不会误变为白色。真实隐藏房入口在打开前仍保留门框，狗牙等排除线索只作用于假候选。

已确认的特殊房间（诅咒房、献祭房、道具房、小头目房、刺房、商店、骰子房、书房、宝箱房等）不能与超级隐藏房相连：其邻格仅在另有房墙、达到至少两面时显示白色普通隐藏房候选；单面特殊房墙旁没有候选。特殊房入口正对面的外墙属于死路，两种候选都排除；当前房间使用实际房门方向，已离开的房间使用 GoodTripPlus 保存的门位证据。大 BOSS 房与两种隐藏房均不能相连，任何紧邻大 BOSS 房的位置都排除候选。未进入的房间若在小地图上已显示可辨识的特殊房或骷髅图标，其类型已经公开，立即按对应规则筛选；仅显示灰色房格时仍视作类型未知，也不会预读入口方向。

进入本层所有普通房间后，未探索的原始房间只可能是尽头特殊房间，不会再补出普通隐藏房所需的第二面普通房墙。仅与一面已知普通房墙相邻的位置固定为金色超级隐藏房候选；仅与一面类型未知的房墙相邻的位置清除，因为它不可能是超级隐藏房。达到至少两面已知房墙的位置仍为白色普通隐藏房候选。红钥匙创建的房间不计入本层原始普通房间的探索进度。

获得藏宝图（道具 54）或使用世界（卡牌 22）后，地图已公开的房间位置和外形立即参与候选计算。整层原始非隐藏房的位置均显示后，一面普通房墙旁固定为金色超级隐藏房候选，至少两面房墙旁固定为白色普通隐藏房候选，不再保留白金交替；只有一面特殊房墙、特殊房入口正对面、或紧邻大 BOSS 房的位置均不显示。已公开的特殊房和骷髅图标同样参与筛选；只有灰色房格时仍不读取实际房间类型与门位。星号按地图显示设置绘制，门框只绘制当前房间可用入口；未揭露的真实隐藏房位置不会直接公开。世界牌的整层布局状态在换层时清除。

门框功能源自独立模组 Secret Candidate Outlines，由 [clawsleep](https://github.com/clawsleep) 贡献，候选数据与排除逻辑使用 [Lazy Delver](https://github.com/dokee39/IsaacLazyDelver)（作者 dokee）的集成模块。

检测性能：主动道具使用后只在对应的短时间窗口追踪岩石波；怪物和鸟肥笼来源在进房时登记，房内新生成的来源也会登记。没有待追踪来源时，碎石波检测会立即返回。门框候选在地图数据刷新或换房时重算，并每 30 帧兜底核对一次；只有双类型候选门框的颜色与透明度逐帧变化。

硫酸（463）与地球（592）的破墙泪弹继续按实际撞墙位置排除假候选；当前房间使用数据破解（481）后也允许检查其临时随机泪弹效果。只有当前房间存在相邻假候选，且玩家持有硫酸、地球、水果蛋糕（418）的效果之一，或本房间用过数据破解时，才读取攻击实体的破墙标志；持有状态每帧最多检查一次，数据破解的使用记录在换房时清除。三美元纸币（191）经游戏内实测不能打开隐藏房门，已从检测来源移除。安装 REPENTOGON 时仅在泪弹撞击网格的回调中检测泪弹；原版游戏没有该回调，仍按泪弹更新检查碰撞。攻击方式变为硫磺火、科技 X 等激光后，带有破墙标志的直线光束按终点、圆环按圆周与候选门位的接触位置排除假候选；剖腹产产生的胎儿若保留破墙标志并触发泪弹撞墙，仍走泪弹检测。其他模组若直接赋予破墙标志，却不提供上述道具或使用状态，此门禁不会识别该来源。

激光子类型 4（`No Impact`，如 Tech Zero）的无命中特效不等于无碰撞；其破墙行为尚未确认，当前圆环检测保守跳过此类型。

服用 “I can see forever!” 后，会同步更新当前及之后经过房间的普通／超级隐藏房候选：排除这些房间相连的假候选，星号与门框一起刷新，无需打开地图；真实隐藏房与究极候选保留。

## 已知问题

- 2.6.12 会在需要时沿真实通路中转，避免隐藏房传向相邻可达房间时误炸开未打开的隐藏墙；只使用原生 API，不依赖 REPENTOGON。中转会实际经过其它房间，因此沙漏可能回到中转房或更早状态，无法保证回到最初出发房，这是接受的已知限制。

## 打包

开发者可在模组目录运行 `./pack.sh`，生成 `dist/goodtripplus-<版本>.zip`。分发时请保留包内许可证文件。
